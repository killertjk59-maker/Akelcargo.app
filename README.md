# Akelcargo

Барномаи пайгирии бор аз Чин ба Тоҷикистон (PWA + панели админ).

## Воридшавии муштарӣ
1. Рақами телефонро нависед (масалан `99290XXXXXXX`).
2. Рамзи 4-рақама ба экрани WhatsApp меояд (демо). Барои WhatsApp-и воқеӣ Cloud API-ро дар админ пайваст кунед.
3. Рамзро ворид кунед.

## Админ
- Нишонӣ: `/admin`
- Телефон: `992900000001`
- Рамз: `AkelAdmin2026`

Админ метавонад:
- треккод илова/таҳрир кунад (санаи қабул, статус, вазн, нарх, телефони муштарӣ)
- хабар ба ҳама фиристад
- суроғаи анбор, тариф, ҷадвал, шартҳо, молҳои манъ, дастгирӣ, баннер, дарсҳоро иваз кунад
- WhatsApp Cloud API-ро пайваст кунад

## Насб ҳамчун барнома
Дар Chrome/Samsung Internet: меню → **Add to Home screen** / **На экран «Главная»**.
Номи барнома: **Akelcargo**.

## Оғоз
```
npm install
npm run dev
```
